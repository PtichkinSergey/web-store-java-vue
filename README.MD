# Инструкция по запуску
## Подготовка
1. Скачайте и установите JDK 8 с официального сайта oracle.com
2. Проверьте, что JDK корректно установлен, введя в командной строке java -version
3. Для тестирования дополнительно установите переменную среды JAVA_HOME, указав путь до папки bin вашего JDK
4. Скачайте и установите docker desktop с официального сайта: https://www.docker.com/products/docker-desktop/
5. Запустите docker и убедитесь, что docker engine запущен
6. Скачайте репозиторий
7. Перейдите в директорию: webstore\backend\src\main\resources\
8. В файле application.properties замените переменные spring.mail.* на свои данные любого почтового аккаунта. При наличии двухфакторной аутентификации, нужно создать пароль приложения. (Необходимо для отправки заказа по почте, иначе выведет код 500)
9. Для запуска тестов дополнительно установите maven : https://maven.apache.org/download.cgi и добавьте путьк папке bin в переменную Path

## Сборка и запуск
1. Для сборки проекта перейдите в директорию webstore.
2. В командной строке введите:
```
docker compose build 
```
3. Запустите проект командой:
```
docker compose up
```

## Проверка работоспособности и тестирование
1. Для начала проверьте, что все контейнеры успешно запущены. Для этого введите команду:
```
docker ps
```
Должно быть поднято 4 контейнера: backend, frontend, webstore-postgresqldb, pgadmin_container

2. Проверка заполнения базы данных.
- Для проверки наполнения базы данных postgres перейдите в браузере на адрес
```
http://localhost:5050
```
- Потребуется пароль для входа: 
```
password
```
- Перейдите в левой панели по пути servers - Databases - webstore - Schemas - pablic - tables. Должно быть создано 7 таблиц. 

Если по каким то причинам база данных пуста, инициализируйте её в ручную: 
- В корне проекта откройте файл database.sql и скопируйте содержимое.
- Откройте запросник в pgAdmin и вставьте туда запрос.
- Выполните запрос и убедитесь в отсутствии ошибок.

3. Проверка работоспособности приложения. 
- Перейдите на адрес:
```
http://localhost:8080
```
- Зарегистрируйтесь и попробуйте добавить товары в корзину
- Для выборки товаров можно использовать выпадающее меню слева
- Перейдите в корзину и осуществите заказ

4. Тестирование приложения.
- Для запуска тестов перейдите в каталог webstore\backend
- Проверьте что у вас установлен maven:
```
mvn -version
```
- Запустите команду:
```
mvn test
```
